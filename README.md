# Кадры — учёт персонала (Blazor Server, .NET 10)

Веб-приложение для учёта отделов, должностей, сотрудников и начислений по отработанным часам.

## Быстрый запуск

Скрипт сам установит .NET 10 SDK (если его нет), восстановит пакеты, соберёт и запустит приложение.

| Система | Как запустить |
|---|---|
| Windows | двойной клик по `start.cmd` (или `.\start.ps1` в PowerShell) |
| macOS / Linux | `./start.sh` в терминале |

После запуска откройте http://localhost:5115.

**Демо-вход:** `hr@demo.ru` / `Demo123!`. Можно зарегистрировать и свой аккаунт.

## Что внутри

- **Стек:** Blazor Server (Interactive Server), ASP.NET Core Identity, Entity Framework Core, SQLite.
- **База данных** — файл `poly/hr.db`. Создаётся автоматически при первом запуске, миграции применяются сами.
- **Демо-данные** (4 отдела, 5 должностей, 9 сотрудников, начисления за последние две недели) добавляются только в пустую базу. Чтобы начать с чистого листа, удалите `poly/hr.db` и перезапустите приложение.

## Разделы

- **Аналитика** — численность, фонд оплаты, распределение по отделам.
- **Отделы** — создание и удаление; отдел с сотрудниками удалить нельзя.
- **Должности** — справочник с почасовой ставкой; занятую должность удалить нельзя.
- **Сотрудники** — приём, редактирование (в т.ч. перевод в другой отдел), поиск, фильтр по отделу, печать ведомости, карточка сотрудника.
- **Зарплаты** — учёт отработанных часов; ставка подставляется из должности.

## Запуск вручную

```bash
dotnet run --project poly --launch-profile http
```

Требуется .NET 10 SDK: https://dotnet.microsoft.com/download/dotnet/10.0
